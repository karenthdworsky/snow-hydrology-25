Setup

All radiation components were computed from the Telluride ASOS (TEX) station WY2024 data. Longwave radiation used an all-sky emissivity approach; shortwave used a solar geometry model accounting for cloud cover fraction.

1. Net Longwave Radiation

All-sky emissivity (Brutsaert 1975 modified): ε_all = 0.83 − 0.18 × exp(−0.067 × √ea)

Net longwave = ε_all × σT⁴ − σT⁴ = (ε_all − 1) × σT⁴

ggplot(data, aes(x = datetime, y = lw_net)) +
  geom_line(color = "#d73027", linewidth = 0.6) +
  geom_hline(yintercept = 0, linetype = "dashed", color = "gray50") +
  labs(title = "Net Longwave Radiation — Telluride ASOS (WY2024)",
       x = "Date", y = "Net Longwave Radiation (W/m²)") +
  theme_minimal() +
  theme(plot.title = element_text(hjust = 0.5, face = "bold"),
        axis.text.x = element_text(angle = 45, hjust = 1))

2. Incoming and Net Shortwave Radiation

Incoming shortwave computed from solar geometry (Spencer 1971, Spencer 1971 equation of time), attenuated by cloud cover fraction using the Kasten-Young cloudiness transmissivity: HK_in = I_sc × E₀ × cos(Z) × (0.355 + 0.68 × (1 − C_cloud))

sw_plot <- data %>%
  filter(!is.na(HK_in) & !is.na(HK_star)) %>%
  select(datetime, HK_in, HK_star) %>%
  pivot_longer(cols = c(HK_in, HK_star),
               names_to = "variable", values_to = "W_m2")

ggplot(sw_plot, aes(x = datetime, y = W_m2, color = variable)) +

3. Cumulative Net Energy Balance

The cumulative energy balance combines net longwave, net shortwave, and energy added by precipitation (rain-on-snow heat flux).

4. Monthly Average Radiation Components

monthly_rad <- data %>%
  mutate(month = floor_date(datetime, "month")) %>%
  group_by(month) %>%
  summarise(
    mean_lw_net  = mean(lw_net,  na.rm = TRUE),
    mean_HK_star = mean(HK_star, na.rm = TRUE),
    .groups = "drop"
  ) %>%
  pivot_longer(cols = c(mean_lw_net, mean_HK_star),
               names_to = "component", values_to = "W_m2")

ggplot(monthly_rad, aes(x = month, y = W_m2, fill = component)) +
  geom_col(position = "dodge", alpha = 0.85) +
  geom_hline(yintercept = 0, linetype = "dashed") +
  scale_fill_manual(name = "Component",
                    values = c("mean_lw_net" = "#d73027", "mean_HK_star" = "#2166ac"),
                    labels = c("mean_lw_net" = "Net Longwave",
                               "mean_HK_star" = "Net Shortwave")) +
  scale_x_datetime(date_labels = "%b %Y") +
  labs(title = "Monthly Average Radiation Components — Telluride ASOS (WY2024)",
       x = "Month", y = "Average Radiation (W/m²)") +
  theme_minimal() +
  theme(legend.position = "bottom",
        axis.text.x = element_text(angle = 45, hjust = 1),
        plot.title = element_text(hjust = 0.5, face = "bold"))
